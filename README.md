# Native64

Native64 面向本地推理和私有化部署，提供模型压缩、批量推理优化和指定设备的适配评估。重点是在已有硬件上提高批量处理能力，并按模型的实际任务验证输出质量。

## 代表实测

同一台 RTX 3060 12 GB，Qwen3.5-9B 文本推理，八路合计缓存解码吞吐。

| Native64 路线 | 并行请求 | 每路上下文 | Native64 | 对照 | 对照吞吐 |
|---|---:|---:|---:|---|---:|
| 混合精度 | 8 | 4,096 token | **264.98 token/s** | llama.cpp Q4_K_M | 157.02 token/s |
| 八位推理 | 8 | 1,024 token | **206.59 token/s** | llama.cpp Q8_0，启用 CUDA Graph | 152.79 token/s |

两行是独立的固定批次测试。计时从批次预填充完毕后开始，指标为稳态解码吞吐。[性能对照口径](docs/benchmark-method.md)

## 工程覆盖

工程归档覆盖 Qwen3.5-9B、SmolLM3-3B、OLMoE、Mamba-130M、Whisper-small、CLIP ViT-B/32、VideoMAE Base 和 DiT-XL/2-256，共八个模型。文本、语音、检索、视频和生成任务分别采用适合自身的质量指标。各模型的实际收益随设备和工作负载变化。

## 演示样品

[汇总数据样品](examples/qwen35-9b-b8.json)提供一组已归档的八位推理结果。运行下面的命令会从样品生成 Markdown 对照表，并计算相对吞吐变化。

```bash
python -X utf8 examples/render_report.py
```

示例读取现成的汇总结果并生成报告。[样品运行说明](examples/README.md)
